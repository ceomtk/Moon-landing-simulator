# Moon Landing Simulator

Version 1.0

Simple Python terminal-based Moon mission simulator.

Features:
- Rocket component system
- Fuel management
- Earth launch
- Earth Orbit phase
- Moon transfer
- Random landing scenarios
- Moon landing

Things i've trained: 
- Python
- Classes (OOP)
- Functions
- Loops
- Dictionaries
- Random events

Planned features for future versions:

- Return to Earth mission
- Repair system
- Mission log
- More random events
- Multiple rockets
- Space station / Moon base
- Visual terminal effects
